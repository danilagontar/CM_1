# Эмулятор командной оболочки

Эмулятор командной строки UNIX-подобной операционной системы, разработанный на Python. Проект реализуется поэтапно в рамках практической работы по конфигурационному управлению.

## Возможности

На первом этапе реализованы:

* консольный интерфейс CLI
* динамическое приглашение с именем пользователя и именем компьютера
* разбор команд и аргументов
* раскрытие переменных окружения реальной ОС
* команды-заглушки `ls` и `cd`
* команда `exit`
* обработка неизвестных команд
* обработка некорректных аргументов
* автоматические тесты

В следующих этапах планируется реализация конфигурации запуска, виртуальной файловой системы и дополнительных команд.

## Структура

```text
src/       исходный код проекта
tests/     автоматические тесты
run.sh     запуск эмулятора
```

## Запуск

Требуется Python 3.

```bash
./run.sh
```

```bash
python -m src.main
```
## Тестирование

Для запуска тестов используется pytest:

```bash
pytest
```

## Пример

```text
user@computer:~$ ls test.txt
ls test.txt

user@computer:~$ cd test
cd test

user@computer:~$ unknown
Error: unknown command: unknown

user@computer:~$ exit
```

На первом этапе `ls` и `cd` являются заглушками и не изменяют виртуальную файловую систему.
