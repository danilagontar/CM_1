# Эмулятор командной оболочки

Эмулятор командной строки UNIX-подобной операционной системы, написанный на Python. Проект выполняется поэтапно в рамках практической работы по конфигурационному управлению.

### Этап 1

На первом этапе реализованы:

* консольный интерфейс
* команды `ls` и `cd` в виде заглушек
* команда `exit`
* обработка неизвестных команд
* обработка ошибок
* автоматические тесты

### Этап 2

На втором этапе добавлена возможность задавать параметры запуска эмулятора:

* путь к виртуальной файловой системе через `--vfs` 
* собственное приглашение через `--prompt`
* стартовый скрипт через `--script`
* остановка скрипта при первой ошибке
* обработка ошибок при работе со стартовым скриптом

Также добавлены несколько `.sh`-скриптов для проверки параметров запуска.

## Параметры запуска

Эмулятор поддерживает три параметра командной строки.

### `--vfs`

Указывает путь к виртуальной файловой системе.

Пример:

```
python3 -m src.main --vfs "./test-vfs-1.csv"
```

### `--prompt`

Позволяет изменить приглашение командной строки.

Пример:

```
python3 -m src.main --prompt "my-shell$ "
```

### `--script`

Указывает файл со стартовыми командами.

Пример:

```
python3 -m src.main --script "./scripts/startup.sh"
```

Параметры можно использовать одновременно:

```
python3 -m src.main --vfs "./test-vfs-1.csv" --prompt "shell-1$ " --script "./scripts/startup.sh"
```

При запуске программы выводятся переданные параметры:

```
VFS path: ./test-vfs-1.csv
Prompt: shell-1$ 
Startup script: ./scripts/startup.sh
```

## Стартовый скрипт

Стартовый скрипт содержит команды, которые эмулятор выполняет автоматически при запуске.

Пример файла `scripts/startup.sh`:

```text
ls
cd test
ls file.txt
exit
```

Во время выполнения скрипта отображаются как команды, так и их результат:

```text
shell-1$ ls
ls
shell-1$ cd test
cd test
shell-1$ ls file.txt
ls file.txt
shell-1$ exit
```

Если во время выполнения встречается неизвестная команда, скрипт останавливается.

Например:

```text
shell-1$ ls
ls
shell-1$ unknown
Error: unknown command: unknown
```

Команды после ошибки уже не выполняются.

## Запуск

Для запуска проекта требуется Python 3.

Запуск через `./run.sh`

Запуск напрямую: `python3 -m src.main`

Запуск с параметрами: `python3 -m src.main --vfs "./test-vfs-1.csv" --prompt "custom-shell$ " --script "./scripts/startup.sh"`

## Тестирование

Для запуска автоматических тестов используется `pytest`

## Пример работы

```
user@computer:~$ ls test.txt
ls test.txt

user@computer:~$ cd test
cd test

user@computer:~$ unknown
Error: unknown command: unknown

user@computer:~$ exit
```

На данном этапе команды `ls` и `cd` пока являются заглушками и не выполняют реальные операции с виртуальной файловой системой.
